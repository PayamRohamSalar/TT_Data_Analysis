# فاز ۰ — طراحی استراتژی نمونه‌گیری

این پوشه، کدهای اصلی طراحی استراتژی نمونه‌گیری پروژه است که در همکاری با دانشگاه الزهرا تهیه و در قالب دو گزارش برای بانک توسعه تعاون ارسال شد. کد اصلی در `D:\OneDrive\AI-Project\Tosee_Taavon` نوشته شده بود و در تاریخ ۲۰۲۶-۰۸-۲۹ به این پروژه (`TT_DataAnalysis`) منتقل شد.

مستندسازی کامل روش‌شناسی (مبانی نظری RFM، صدک‌ها، فرمول کوکران، نتایج نهایی حجم نمونه) در [`docs/07_sampling_methodology.md`](../../docs/07_sampling_methodology.md) آمده است. این پوشه فقط کد اجرایی و خروجی‌های آن را نگه می‌دارد.

## ⚠️ نکته‌ی مهم برای فاز ۱ به بعد

این طراحی نمونه‌گیری بر این فرض بود که بانک فقط فایل‌های **توزیعی/خلاصه‌شده** (نه دیتابیس خام) در اختیار پروژه می‌گذارد. در عمل، بانک یک بک‌آپ کامل SQL Server (`Alzahra_Final_DB`) با تمام ۷.۴ میلیون مشتری و کل تراکنش‌های ۶۸ ماهه تحویل داد (شرح در `docs/EXECUTION_LOG.md`). بنابراین:
- **فاز ۱** (گزارش وضعیت بازار/رفتار مشتریان) روی **سرشماری کامل جمعیت فعال** (با همان تعریف RFM مستندشده در این پوشه) انجام می‌شود، نه روی نمونه‌ی طبقه‌بندی‌شده‌ی این گزارش.
- طرح نمونه‌گیری همین‌جا (۲۶۸,۱۶۹ سپرده‌گذار حقیقی، ۵۸,۵۱۳ حقوقی، ۲۵۶,۷۱۳ تسهیلات‌گیرنده حقیقی، ۲۷,۳۳۵ حقوقی) برای **فازهای ۲ و ۴** (خوشه‌بندی، مدل‌سازی پیش‌بینی) نگه داشته می‌شود، جایی‌که کنترل حجم داده برای کارایی الگوریتم و تفکیک train/val/test واقعاً لازم است.

- کدها هنوز به `pip install -e .` این پروژه یا `src/tt_bank/` وابسته نیستند (اسکریپت‌های مستقل‌اند)؛ پکیج خالی `src/tt_bank/phase0_sampling/` صرفاً برای هم‌ترازی با ساختار سایر فازها ساخته شده.

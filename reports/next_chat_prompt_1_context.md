## ۶. قید اکید بانک درباره‌ی شعب (نقض‌ناپذیر)

بانک تأکید کرده که ارائه‌ی نکات عملکردی درباره‌ی شعب حساسیت‌زاست. بنابراین:

## ۷. وضعیت زیرساخت

- SQL Server محلی در حالت تک‌کاربره (`-m`) است و **اتصال دوم را رد می‌کند**. در هر اسکریپت فقط یک engine
  بساز و دو اسکریپت را هم‌زمان اجرا نکن.
- پایتون را مستقیم اجرا کن: `D:\Conda\envs\tt_env\python.exe -u <script>`.
  دستور `conda run ... | Tee-Object` در پس‌زمینه گیر می‌کند.

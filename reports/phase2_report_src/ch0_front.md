# گزارش نهایی فاز ۲

## تحلیل رفتار مشتریان بانک توسعه تعاون: خوشه‌بندی مشتریان

---

**مشخصات سند**

| | |
|---|---|
| **عنوان** | گزارش خوشه‌بندی مشتریان، فاز ۲ |
| **منبع داده** | پایگاه تحلیلی بانک (۱۴ جدول) و آمار ماهانه‌ی رسمی بانک در سطح استان و شعبه |
| **بازه‌ی تحلیل** | ۰۱/۱۴۰۰ تا ۱۲/۱۴۰۴ (پنج سال) |
| **آخرین مقطع** | ۱۲/۱۴۰۴ |
| **واحد پولی** | هزار میلیارد تومان (همت) |
| **تاریخ تدوین** | آبان ۱۴۰۵ |
| **وضعیت** | پیش‌نویس کامل جهت بازبینی |

---

**راهنمای مطالعه**

این گزارش مشتریان بانک توسعه تعاون را بر پایه‌ی رفتار سپرده‌گذاری و بهره‌مندی از تسهیلات به گروه‌هایی تقسیم می‌کند و ارزش، ریسک، مهاجرت و پراکندگی جغرافیایی هر گروه را بررسی می‌کند. برای مدیران و کارشناسانی نوشته شده است که با روش‌های آماری آشنایی عمیق ندارند؛ از این رو مفاهیم فنی در نخستین کاربرد توضیح داده می‌شوند و نتایج در متن و جدول‌ها به زبان مدیریتی بیان می‌شوند. ارقام مطلق گزارش بر پایه‌ی پایگاه تحلیلی بانک‌اند و با واحد هزار میلیارد تومان آمده‌اند.
